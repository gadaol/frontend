## 인증 라우팅

- 미인증: `/`, `/auth` 접근 가능
- 인증 필요: `/home`, `/trips/*`, `/backlog`, `/mypage`, `/notifications`
- 인증 후 `/` 접근 시 `/home` 리다이렉트

---

## 화면 상세

### 온보딩 — `/`

**목적:** 앱 첫 인상, 핵심 가치 전달, 로그인 유도

**접근:** 비인증 유저 (인증 시 /home 리다이렉트)

**노출 내용:**
- 슬로건: "같이 가다, 함께 올게"
- 핵심 기능 3가지 소개 (실시간 공유 / 백로그 / AI 추천)
- 시작하기 버튼 → `/auth`

---

### 로그인/회원가입 — `/auth`

**목적:** 소셜 로그인

**노출 내용:**
- Google 로그인 버튼
- (추후) Apple, Kakao

**액션:**
- 로그인 성공 → `/home`

---

### 홈 — `/home`

**목적:** 진행 중/예정 여행 빠른 접근, 알림 요약

**노출 내용:**
- 진행 중인 여행 카드 (있을 경우)
- 예정된 여행 목록
- 최근 백로그 항목
- 읽지 않은 알림 배지

**액션:**
- 여행 카드 클릭 → `/trips/:id`
- 새 여행 만들기 → `/trips/new`

---

### 여행 목록 — `/trips`

**목적:** 전체 여행 조회

**노출 내용:**
- 탭: 예정 / 진행 중 / 완료
- 여행 카드: 커버 이미지, 제목, 날짜, 멤버 아바타

**액션:**
- 카드 클릭 → `/trips/:id`
- FAB → `/trips/new`

---

### 여행 만들기 — `/trips/new`

**목적:** 새 여행 생성

**폼 필드:**
- 제목 (필수)
- 시작일 / 종료일
- 커버 이미지 (선택)
- 태그 선택

**액션:**
- 생성 완료 → `/trips/:id`

---

### 여행 상세 — `/trips/:id`

**목적:** 여행 overview, 일정 요약, 멤버 현황

**노출 내용:**
- 커버 이미지, 제목, 날짜
- 멤버 아바타 목록
- 일정 요약 (일자별)
- 투표 현황

**액션:**
- 일정 편집 → `/trips/:id/edit`
- 장소 검색 → `/trips/:id/places`
- 메이트 초대 → `/trips/:id/invite`

---

### 일정 편집 — `/trips/:id/edit`

**목적:** 실시간 협업 일정 편집

**기능:**
- 일자별 장소 드래그 정렬
- 장소 추가/삭제
- 메모 입력
- Supabase Realtime으로 멤버 동시 편집 반영

---

### 장소 검색 — `/trips/:id/places`

**목적:** Google Places API로 장소 검색 후 일정 추가 또는 투표

**노출 내용:**
- 검색창
- 검색 결과 리스트 (이름, 주소, 카테고리)
- 지도 뷰 (선택)

**액션:**
- 장소 클릭 → `/places/:id`
- 일정에 추가
- 백로그에 추가
- 투표

---

### 장소 상세 — `/places/:id`

**목적:** 장소 정보 상세 조회

**노출 내용:**
- 이름, 주소, 카테고리
- 지도
- 리뷰 목록
- 투표 수

**액션:**
- 일정에 추가
- 백로그에 추가

---

### 메이트 초대 — `/trips/:id/invite`

**목적:** 여행 멤버 초대

**기능:**
- 초대 링크 생성/복사
- 역할 설정 (editor / viewer)
- 현재 멤버 목록 / 역할 변경

---

### 백로그 — `/backlog`

**목적:** 못 간 곳 모아보기, 다음 여행에 활용

**노출 내용:**
- 백로그 장소 카드 목록
- 어느 여행에서 저장했는지 표시
- 메모

**액션:**
- 장소 클릭 → `/places/:id`
- 삭제
- 여행에 추가

---

### 마이페이지 — `/mypage`

**목적:** 프로필 관리, 구독 현황

**노출 내용:**
- 아바타, 이름
- 구독 플랜 (free / pro / team)
- 내가 만든 여행 수, 다녀온 장소 수

**액션:**
- 프로필 편집
- 구독 관리 → `/subscription` (v2)
- 로그아웃

---

### 알림 — `/notifications`

**목적:** 초대, 투표, 일정 편집 알림 수신

**노출 내용:**
- 알림 리스트 (타입별 아이콘, 내용, 시간)
- 읽음/안읽음 구분

**액션:**
- 알림 클릭 → 해당 여행/장소로 이동
- 전체 읽음 처리
